# VPN Service Bot — шаблон Telegram-бота

Готовая оболочка для продажи VPN-подписок. Она не управляет VPS и не меняет конфигурацию 3x-ui сама: после подтверждения заказа создаётся запись о подписке, а метод `provision_vpn()` — единственная точка, куда позже подключается API вашей 3x-ui панели.

## Уже есть

- пользовательское меню: тарифы, профиль, покупка, ввод промокода;
- админ-панель по `/admin`: тарифы, способы оплаты, промокоды и подтверждение заказов;
- SQLite-база, создаваемая автоматически;
- ручные/ссылочные способы оплаты: пользователь видит инструкцию, нажимает «Я оплатил», а администратор подтверждает заказ;
- скидки промокодов в процентах, с лимитом активаций и датой завершения.
- одноразовый пробный период на 3 дня: его факт хранится отдельно от подписки, поэтому удаление подписки в админке не даёт получить триал повторно.

## Запуск

1. Установите Python 3.10+.
2. Создайте виртуальное окружение и установите зависимости:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env`, вставьте токен BotFather и свой числовой Telegram ID.
4. Запустите: `python bot.py`.

Узнать свой ID можно через бота вроде `@userinfobot`. Панель открывается командой `/admin` только для ID из `ADMIN_IDS`.

## Добавление оплаты

В админке: «Способы оплаты» → «Добавить способ». Укажите название и инструкцию. В инструкции можно написать реквизиты, ссылку на оплату или текст для пользователя. Это подходит для ручной проверки переводов, Crypto Bot invoice URL, ЮKassa payment link и т.п.

Для автоматического провайдера замените код в `create_order_payment()` (создание счёта) и/или добавьте webhook, который вызывает `confirm_order()` после успешной оплаты. Не кладите секретные ключи в исходный код — храните их в `.env`.

## Подключение 3x-ui

Заполните параметры `3XUI_*` в `.env`, затем реализуйте запросы API в функции `provision_vpn()` в `bot.py`. Она получает `telegram_id`, число дней и ID заказа; должна вернуть строку подключения (VLESS/VMess/Trojan) или вызвать `RuntimeError` с понятной причиной. Серверы и инбаунды вы продолжаете создавать и настраивать в 3x-ui напрямую.

Перед запуском в продакшене используйте HTTPS для webhook-оплат и делайте резервную копию файла базы `vpn_bot.sqlite3`.
