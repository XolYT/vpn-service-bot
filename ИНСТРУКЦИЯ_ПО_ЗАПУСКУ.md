# Подробный запуск VPN Service Bot на Windows

Эта инструкция запускает бота на вашем компьютере в режиме polling: отдельный публичный домен и webhook пока не нужны. Компьютер должен оставаться включённым, пока бот работает.

## 1. Что потребуется

- аккаунт Telegram;
- токен бота от `@BotFather`;
- ваш числовой Telegram ID — именно число, не `@username`;
- установленный Python версии 3.10 или новее;
- папка с этим проектом: `C:\Users\PC\Desktop\Vpn сервис`.

Доступ к 3x-ui и платёжным системам для первого старта не нужен. Их можно подключить позже.

## 2. Создать бота у BotFather

1. В Telegram откройте [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Укажите отображаемое имя, например `My VPN`.
4. Укажите username, который обязательно заканчивается на `bot`, например `my_company_vpn_bot`.
5. BotFather пришлёт строку вида `123456789:AA...`. Это `BOT_TOKEN`.

Токен равнозначен паролю от бота. Не пересылайте его посторонним, не сохраняйте в GitHub и не вставляйте в сообщения поддержки.

Дополнительно в BotFather можно выполнить `/setdescription`, `/setabouttext` и `/setuserpic`, чтобы оформить профиль бота.

## 3. Узнать свой Telegram ID

Откройте `@userinfobot` в Telegram, нажмите Start и скопируйте значение `Id` — например `123456789`.

Этот ID нужен для доступа к админ-панели. Username (`@name`) не подходит. Если администраторов несколько, их ID перечисляют через запятую без пробелов или с пробелами:

```text
ADMIN_IDS=123456789,987654321
```

## 4. Установить Python

1. Скачайте Python с [официального сайта](https://www.python.org/downloads/windows/).
2. Запустите установщик.
3. На первом экране обязательно установите галочку **Add python.exe to PATH**.
4. Нажмите Install Now.
5. Откройте PowerShell и проверьте установку:

```powershell
python --version
```

Должна отобразиться версия 3.10 или выше. Если команда не найдена, закройте PowerShell, откройте его заново. При необходимости вместо `python` далее используйте `py`.

## 5. Открыть PowerShell в папке проекта

Нажмите `Win + R`, введите `powershell` и выполните:

```powershell
cd "C:\Users\PC\Desktop\Vpn сервис"
```

Проверка содержимого папки:

```powershell
Get-ChildItem
```

В списке должны быть `bot.py`, `requirements.txt` и `.env.example`.

## 6. Создать виртуальное окружение и установить пакеты

В той же консоли последовательно выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

После активации в начале строки PowerShell появится `(.venv)`. Это означает, что зависимости установятся только для этого проекта и не затронут другие программы.

Если PowerShell заблокировал выполнение скрипта `Activate.ps1`, выполните один раз в этой же консоли:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Затем снова выполните `.\.venv\Scripts\Activate.ps1`.

## 7. Создать и заполнить файл настроек

Создайте персональный файл `.env` из примера:

```powershell
Copy-Item .env.example .env
notepad .env
```

В открывшемся Блокноте замените две строки на свои значения:

```ini
BOT_TOKEN=123456789:сюда_вставьте_полный_токен_от_BotFather
ADMIN_IDS=123456789
DATABASE_PATH=vpn_bot.sqlite3
```

If buttons react slowly or the Telegram API is unavailable from your network, add a stable proxy to the same file and restart the bot:

```ini
TELEGRAM_PROXY=socks5://127.0.0.1:1080
```

`http://host:port` and `https://host:port` are supported as well. This proxy is only for the bot's connection to Telegram.

Сохраните файл (`Ctrl+S`) и закройте Блокнот. Убедитесь, что файл называется именно `.env`, а не `.env.txt`: в проводнике включите «Расширения имён файлов», если сомневаетесь.

`.env` и `vpn_bot.sqlite3` уже исключены из Git через `.gitignore`; всё равно не выкладывайте их в общий доступ.

## 8. Первый запуск

В PowerShell, в папке проекта и с активным `(.venv)`, выполните:

```powershell
python bot.py
```

При первом запуске появится файл базы данных `vpn_bot.sqlite3`, а в консоли появятся служебные сообщения. Оставьте это окно открытым.

Откройте созданного бота в Telegram, нажмите **Start** или отправьте `/start`. Должны появиться кнопки покупки, тарифов, профиля и промокода.

Чтобы корректно остановить бота, вернитесь в окно PowerShell и нажмите `Ctrl+C`.

## 9. Первичная настройка через админку

1. Напишите своему боту `/admin` именно с того Telegram-аккаунта, чей ID указан в `ADMIN_IDS`.
2. Откройте «Тарифы». Три демонстрационных тарифа уже добавлены. Можно удалить их и добавить собственные.
3. Нажмите «Добавить тариф» и отправьте одно сообщение в формате:

   ```text
   На 1 месяц | 30 | 299
   ```

   Здесь: название | срок в днях | цена в рублях.

4. Откройте «Способы оплаты» → «Добавить способ» и отправьте, например:

   ```text
   Перевод СБП | Переведите сумму на +7 900 000-00-00, затем нажмите «Я оплатил».
   ```

   Пользователь увидит эту инструкцию после выбора тарифа. Он отметит оплату, а вам придёт кнопка подтверждения заказа.

5. Для промокода выберите «Промокоды» → «Добавить промокод» и отправьте, например:

   ```text
   START20 | 20 | 100 | 2027-01-01
   ```

   Здесь: код | скидка в процентах | общий лимит использований | дата окончания. Вместо даты можно поставить `-`, если срока нет:

   ```text
   FRIEND10 | 10 | 50 | -
   ```

6. Проверьте пользовательский сценарий с другого Telegram-аккаунта: `/start` → «Купить VPN» → тариф → способ оплаты → «Я оплатил». Администратор получает заявку и подтверждает её в `/admin` → «Заказы».

После подтверждения пользователю продлевается срок подписки. Пока 3x-ui не подключена, бот честно сообщает, что ключ выдаётся администратором.

## 10. Повторный запуск

После перезагрузки компьютера откройте PowerShell и выполните:

```powershell
cd "C:\Users\PC\Desktop\Vpn сервис"
.\.venv\Scripts\Activate.ps1
python bot.py
```

Все тарифы, заказы, промокоды и сроки подписок остаются в `vpn_bot.sqlite3`.

## 11. Резервная копия базы

Перед обновлениями или экспериментами остановите бота (`Ctrl+C`) и скопируйте базу:

```powershell
Copy-Item vpn_bot.sqlite3 "vpn_bot.backup-$(Get-Date -Format yyyy-MM-dd-HHmm).sqlite3"
```

Храните копии отдельно от сервера. В базе есть пользовательские ID, заказы и сроки подписок.

## 12. Подключение 3x-ui

В текущем шаблоне серверы по-прежнему настраиваются вами в 3x-ui. Для автоматической выдачи ключа нужно:

1. Обеспечить безопасный доступ к API 3x-ui (предпочтительно через VPN/закрытую сеть или HTTPS); не публиковать панель без защиты.
2. Добавить параметры в `.env`:

   ```ini
   3XUI_BASE_URL=https://адрес-вашей-панели
   3XUI_USERNAME=admin
   3XUI_PASSWORD=сложный_пароль
   ```

3. Реализовать авторизацию и добавление клиента в функции `provision_vpn()` в `bot.py`.

Эта функция вызывается только после ручного подтверждения заказа. Она должна вернуть ссылку подключения VLESS/VMess/Trojan; бот сохранит её и покажет пользователю в профиле. Конкретные API-адреса зависят от версии/сборки 3x-ui, поэтому перед интеграцией проверьте документацию именно своей панели.

## 13. Автоматические оплаты

Шаблон уже подходит для ручной проверки СБП, переводов и оплат по внешней ссылке. Для автоматической оплаты требуется конкретный провайдер и webhook:

- при создании заказа создать счёт через API провайдера;
- передать пользователю ссылку/инвойс;
- принять webhook об успешной оплате по HTTPS;
- проверить подпись webhook и вызвать подтверждение только для оплаченного заказа.

Не подтверждайте оплату только по нажатию пользователем «Я оплатил»: эта кнопка намеренно создаёт лишь заявку для администратора.

## Частые проблемы

### `Заполните BOT_TOKEN в .env`

Файл `.env` не создан, находится не рядом с `bot.py` или токен не заменён. Повторите шаг 7.

### `Заполните ADMIN_IDS в .env` или `/admin` не открывается

Проверьте числовой ID, перезапустите бота после изменения `.env`. Username и номер телефона не подходят.

### `ModuleNotFoundError: No module named 'telegram'`

Не активировано окружение или зависимости не установлены. Выполните шаг 6, затем запуск.

### Бот не отвечает, но ошибок нет

Проверьте, что запущен только один экземпляр `bot.py` с этим токеном. Также в BotFather не должен быть настроен старый webhook; удалите его командой `/deletewebhook` у BotFather или через Telegram Bot API, если ранее использовали вебхук.

### `Conflict: terminated by other getUpdates request`

С этим токеном одновременно запущен другой экземпляр бота. Остановите второй процесс/бот на хостинге и повторите запуск.

### После закрытия PowerShell бот перестал работать

Это ожидаемо: текущий запуск работает внутри открытого окна. Для постоянной работы перенесите проект на Linux VPS и запустите его как сервис systemd (лучше отдельно от панели 3x-ui), либо настройте Планировщик заданий Windows.
